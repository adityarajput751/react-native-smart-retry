# Security Policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/adityarajput751/react-native-smart-retry/security/advisories/new),
not as public issues.

Only the latest minor version receives security fixes.

Queued requests are stored unencrypted by default. See
[Security](README.md#security) for how to keep credentials and sensitive data out of storage.
